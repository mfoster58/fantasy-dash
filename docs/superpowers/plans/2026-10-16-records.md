# Records Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Player stats and All-Time pages with one `/records` record book: a Players tab and a Managers tab, each split into sub-tabs of boards, every existing player board kept and some 50 manager boards added on the same engine.

**Architecture:** The existing board engine (`BoardDef` registry → `Section` → `Board`) is generalised: a definition carries `tab` and `sub` instead of `section`, a row may have a manager subject (`playerId: null`, `userId` set) which `Board` renders with an avatar, and `BoardContext` gains manager inputs (`teamGames`, `managerSeasons`, `managers`) built once per page. Manager boards live in `lib/boards/managers/*.ts` on small helpers (`careerRows`, `seasonRows`, `gameRows`). A new `RecordsView` owns the two tab bars and URL state and renders one `Section` per sub-tab.

**Tech Stack:** TypeScript, React 18, react-router v7, Vitest + Testing Library, pnpm workspace. Commands run from `packages/web` unless stated: `npx vitest run <file>`, `npx tsc --noEmit -p tsconfig.json`; from the repo root `pnpm test`, `pnpm build`.

**Spec:** `docs/superpowers/specs/2026-10-16-records-design.md`

**Deviations from the spec, decided here (the spec is amended in Task 1 step 9):**
- Row subject: instead of a `subject` union, `BoardRow.playerId` becomes `PlayerId | null`; a manager row has `playerId: null` and its manager in `userId`. Same information, no churn in the forty existing row producers and tests.
- Manager win and loss streaks are computed from `teamGames` with the same generic run helper as the other streak boards, not from `lib/streaks.ts` (deleted in Task 8). Same results (every game, chronological, a tie ends the run).
- Board files keep their names (`career.ts`, `extras.ts`, `leaders.ts`, `postseason.ts`); the sub-tab is a registry attribute. New player boards go in `boards/playerMoments.ts` and `boards/playerStreaks.ts`.

## Global Constraints

- Sub-tab ids: players `alltime, moments, streaks, postseason, leaders`; managers `malltime, mseasons, mgames, mstreaks, mplayoffs, mdraft, mtransactions`.
- URL params: `tab=players|managers` (absent = players), `sub=<id>` (absent = first sub-tab of the tab, a sub id from the other tab is ignored), position param = the sub id (players only), season param = `<id>Season`. Switches use `replace: true`.
- In-progress season rule: whole-season rows (Seasons, draft classes, per-season transaction boards) include the in-progress season only when the picker selects it; under All-time they use complete seasons only. Career totals and game rows always include it.
- Minimums: career rate boards need at least one complete season; season rate boards need `games >= 3`; `mtCheap`/`mtCostly` need $25 spent; `mdFirstRound` needs 2 complete seasons.
- Formatting: `fmtPts` (2 dp) for points, `fmtWinPct` (`.643`) for win and all-play percentages, `fmtPct` (`94.2%`) for lineup efficiency, `fmtSigned` for differentials and luck, plain `String` for counts.
- Postseason = tag in `POSTSEASON_TAGS` (QF, SF, Final, 3rd, 5th); consolation = `CONSOLATION_TAGS`; Toilet Bowl = tag `'Toilet Bowl'`.
- Every commit message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Work in a worktree created with the native `EnterWorktree` tool; its Bash hook refuses heredocs and multi-statement commands, so make file changes with the Write/Edit tools and keep shell commands plain.

## Review Focus

2. A manager who left the league: their career rows must still appear with their last season as the span, and `mDrought` must not say "and counting". Pinned in Task 8.
3. A player row and a manager row on the same page use the same `Board`: a manager row must never try to look up `players[null]`. Pinned in Task 2.
4. URL `?tab=managers&sub=moments` (a players sub under managers): must fall back to `malltime`, not render nothing. Pinned in Task 1.
5. The in-progress season chosen explicitly in the Seasons picker must show rows with games so far, and `msFewest` under All-time must not list it. Pinned in Task 6.

```tsx
import { useMemo } from 'react';
import { useSearchParams } from 'react-router';
import type { History, PlayerDirectory, Season } from '@fantasy-dash/core';
import { boardsFor, championsOf, draftValuesOf, lastPlacesOf, type BoardContext, type Tab } from '../../lib/playerBoards';
import { SUB_TABS, TABS, subTabsOf, type SubTab } from '../../lib/boards/tabs';
import { filterLines, flattenLines, isPosFilter, type PosFilter } from '../../lib/playerLines';
import { fitXfp } from '../../lib/xfp';
import Section from '../players/Section';

interface Props { seasons: Season[]; players: PlayerDirectory; managers: History['managers']; years: number[]; currentYear: number; lastScoredWeek: number }
type SeasonPick = number | 'all';

const tabButton = (selected: boolean) => `-mb-px border-b-2 px-3 py-2 text-sm ${selected ? 'border-ink font-medium text-ink' : 'border-transparent text-muted hover:text-ink'}`;

export default function RecordsView({ seasons, players, managers, years, currentYear, lastScoredWeek }: Props) {
  const [params, setParams] = useSearchParams();
  const update = (mutate: (next: URLSearchParams) => void) => { const next = new URLSearchParams(params); mutate(next); setParams(next, { replace: true }); };
  const posOf = (param: string): PosFilter => { const raw = params.get(param); return isPosFilter(raw) ? raw : 'All'; };
  const setPos = (param: string) => (p: PosFilter) => update((next) => { if (p === 'All') next.delete(param); else next.set(param, p); });
  const pickOf = (param: string, fallback: SeasonPick): SeasonPick => {
    const raw = params.get(param);
    if (raw === 'all') return 'all';
    const n = Number(raw);
    return years.includes(n) ? n : fallback;
  };
  const setPick = (param: string, fallback: SeasonPick) => (v: SeasonPick) => update((next) => { if (v === fallback) next.delete(param); else next.set(param, String(v)); });

  const tab: Tab = TABS.find((t) => t.id === params.get('tab'))?.id ?? 'players';
  const subs = subTabsOf(tab);
  const sub = subs.find((s) => s.id === params.get('sub'))?.id ?? subs[0].id;
  const setTab = (id: Tab) => update((next) => { if (id === 'players') next.delete('tab'); else next.set('tab', id); next.delete('sub'); });
  const setSub = (id: string) => update((next) => { if (id === subs[0].id) next.delete('sub'); else next.set('sub', id); });

  const allLines = useMemo(() => flattenLines(seasons, players), [seasons, players]);
  const champions = useMemo(() => championsOf(seasons), [seasons]);
  const lastPlaces = useMemo(() => lastPlacesOf(seasons), [seasons]);
  const picks = useMemo(() => draftValuesOf(seasons), [seasons]);
  const xfp = useMemo(() => fitXfp(allLines), [allLines]);
  const transactions = useMemo(() => seasons.map((s) => ({ year: s.year, transactions: s.transactions })), [seasons]);
  const playerSeasons = useMemo(() => Object.fromEntries(seasons.map((s) => [s.year, s.playerSeasons])), [seasons]);
  const drafts = useMemo(() => Object.fromEntries(seasons.map((s) => [s.year, s.draft])), [seasons]);

  const panel = (s: SubTab) => {
    const pos = s.positions ? posOf(s.id) : 'All';
    const fallback: SeasonPick = s.picker === 'current' ? currentYear : 'all';
    const pick: SeasonPick = s.picker ? pickOf(`${s.id}Season`, fallback) : 'all';
    const year = pick === 'all' ? null : pick;
    const lines = filterLines(allLines, pos).filter((l) => year === null || l.year === year);
    const ctx: BoardContext = { lines, players, champions, lastPlaces, year, currentYear, pos, picks, xfp, transactions, playerSeasons, drafts };
    const note = s.note ?? (year === null ? 'Every season' : `${year} season`);
    const empty = s.id === 'leaders' && year !== null && !allLines.some((l) => l.year === year) ? 'Season has not started.' : null;
    return (
      <Section
        key={s.id}
        id={s.id}
        title={s.title}
        note={note}
        boards={boardsFor(s.tab, s.id)}
        ctx={ctx}
        players={players}
        managers={managers}
```

```ts
import type { PlayoffTag, Season, StandingRow, UserId } from '@fantasy-dash/core';
import { CONSOLATION_TAGS, POSTSEASON_TAGS } from './playerLines';

/** One manager's side of one played game. */
export interface TeamGame {
  year: number; week: number; tag: PlayoffTag | null; gameId: string; matchupId: number;
  userId: UserId; opponentId: UserId;
  points: number; oppPoints: number;
  /** optimal lineup total */
  ceiling: number;
  /** ceiling − points: what the best lineup would have added */
  benchPoints: number;
  projected: number;
  result: 'W' | 'L' | 'T';
  isPlayoff: boolean;
  /** championship bracket */
  postseason: boolean;
  consolation: boolean;
  /** the manager had the week's top score (regular season only, as the data records it) */
  weekHigh: boolean;
}

/** One manager's season, from the standings row plus honors, bracket and games. */
export interface ManagerSeason {
  year: number; userId: UserId; complete: boolean;
  row: StandingRow;
  /** regular-season games played */
  games: number;
  /** sum of benchPoints over every game that season */
  benchPoints: number;
  champion: boolean; runnerUp: boolean; third: boolean; lastPlace: boolean;
  /** appears in the winners bracket */
  playoffBerth: boolean;
  /** regular-season rank */
  seed: number;
}

const round2 = (n: number) => Math.round(n * 100) / 100;

export function teamGamesOf(seasons: Season[]): TeamGame[] {
  const out: TeamGame[] = [];
  for (const s of seasons) {
    for (const wk of s.weeks) {
      if (!wk.played) continue;
      for (const g of wk.games) {
        for (let i = 0; i < 2; i++) {
          const me = g.sides[i];
          const opp = g.sides[1 - i];
          out.push({
            year: s.year, week: wk.week, tag: g.tag, gameId: g.id, matchupId: g.matchupId,
            userId: me.userId, opponentId: opp.userId,
            points: me.points, oppPoints: opp.points, ceiling: me.ceiling, benchPoints: round2(Math.max(0, me.ceiling - me.points)), projected: me.projected,
            result: me.points > opp.points ? 'W' : me.points < opp.points ? 'L' : 'T',
            isPlayoff: wk.isPlayoff,
            postseason: g.tag !== null && POSTSEASON_TAGS.has(g.tag),
            consolation: g.tag !== null && CONSOLATION_TAGS.has(g.tag),
            weekHigh: wk.highScore === me.userId,
          });
        }
      }
    }
  }
  return out;
}

export function managerSeasonsOf(seasons: Season[], games: TeamGame[]): ManagerSeason[] {
  return seasons.flatMap((s) => s.standings.map((row): ManagerSeason => {
    const mine = games.filter((g) => g.year === s.year && g.userId === row.userId);
    return {
      year: s.year, userId: row.userId, complete: s.status === 'complete', row,
      games: row.w + row.l + row.t,
      benchPoints: round2(mine.reduce((t, g) => t + g.benchPoints, 0)),
      champion: s.honors.champion === row.userId, runnerUp: s.honors.runnerUp === row.userId, third: s.honors.third === row.userId, lastPlace: s.honors.lastPlace === row.userId,
      playoffBerth: s.brackets.winners.some((b) => b.home === row.userId || b.away === row.userId),
      seed: row.rank,
    };
  }));
}
```

```ts
/** Longest run of consecutive entries of `weeks` whose key is in the player's set. A run reaching the final week is active. Earliest run wins ties. */
export function longestWeekRun(weeks: WeekRef[], has: Map<PlayerId, Set<number>>): Map<PlayerId, StartRun> {
  const out = new Map<PlayerId, StartRun>();
  const last = weeks[weeks.length - 1];
  for (const [playerId, set] of has) {
    let best: StartRun | null = null;
    let run: { from: WeekRef; to: WeekRef; length: number } | null = null;
    for (const w of weeks) {
      if (!set.has(key(w))) { run = null; continue; }
      if (run === null) run = { from: w, to: w, length: 1 };
      else { run.to = w; run.length += 1; }
      if (!best || run.length > best.length) best = { from: run.from, to: run.to, length: run.length, active: false };
    }
    if (best) out.set(playerId, { ...best, active: last !== undefined && key(best.to) === key(last) });
  }
  return out;
}

/** Every distinct (year, week) in `lines`, in order. */
export const weeksOf = (lines: PlayerLine[]): WeekRef[] => [...new Map(lines.map((l) => [key(l), { year: l.year, week: l.week }])).values()].sort((a, b) => key(a) - key(b));
export const weekKey = key;

export function longestStartRun(lines: PlayerLine[]): Map<PlayerId, StartRun> {
  const startedAt = new Map<PlayerId, Set<number>>();
  for (const l of lines) {
    if (!l.started) continue;
    const set = startedAt.get(l.playerId) ?? new Set<number>();
    set.add(key(l));
    startedAt.set(l.playerId, set);
  }
  return longestWeekRun(weeksOf(lines), startedAt);
}
```

```ts
import type { PlayerId } from '@fantasy-dash/core';
import type { WeekRef } from './ironman';
import type { PlayerLine } from './playerLines';

export interface LineRun { length: number; from: WeekRef; to: WeekRef; lines: PlayerLine[] }

/**
 * Longest run over each player's lines in chronological order where every line passes `pred`.
 * A line that fails ends the run; weeks with no line for the player are simply absent. Earliest run wins ties.
 */
export function longestLineRun(lines: PlayerLine[], pred: (l: PlayerLine) => boolean): Map<PlayerId, LineRun> {
  const byPlayer = new Map<PlayerId, PlayerLine[]>();
  for (const l of lines) { const arr = byPlayer.get(l.playerId) ?? []; arr.push(l); byPlayer.set(l.playerId, arr); }
  const out = new Map<PlayerId, LineRun>();
  for (const [playerId, ls] of byPlayer) {
    ls.sort((a, b) => a.year - b.year || a.week - b.week);
    let best: LineRun | null = null;
    let run: PlayerLine[] = [];
    const flush = () => { if (run.length && (!best || run.length > best.length)) best = { length: run.length, from: { year: run[0].year, week: run[0].week }, to: { year: run[run.length - 1].year, week: run[run.length - 1].week }, lines: run }; run = []; };
    for (const l of ls) { if (pred(l)) run.push(l); else flush(); }
    flush();
    if (best) out.set(playerId, best);
  }
  return out;
}
```

```ts
import type { ManagerSeason, TeamGame } from '../../managerGames';
import type { BoardContext, BoardRow } from '../shared';
import { rank } from '../shared';
import { byManager, type CareerAgg } from './shared';

export interface Run { length: number; from: { year: number; week: number }; to: { year: number; week: number }; active: boolean }
const gameSpan = (r: Run) => `${r.from.year} Wk ${r.from.week} – ${r.to.year} Wk ${r.to.week}`;
const seasonSpan = (r: Run) => (r.from.year === r.to.year ? String(r.from.year) : `${r.from.year}–${r.to.year}`);

/** Longest run of consecutive games (chronological) passing `pred`; a failing game ends it. The later of two equal runs wins. Active when the run reaches the last game. */
export function longestGameRun(games: TeamGame[], pred: (g: TeamGame) => boolean): Run | null {
  const sorted = [...games].sort((a, b) => a.year - b.year || a.week - b.week);
  let best: Run | null = null;
  let run: TeamGame[] = [];
  const flush = (endsAtLatest: boolean) => {
    if (run.length && (!best || run.length >= best.length)) best = { length: run.length, from: { year: run[0].year, week: run[0].week }, to: { year: run[run.length - 1].year, week: run[run.length - 1].week }, active: endsAtLatest };
    run = [];
  };
  sorted.forEach((g, i) => { if (pred(g)) run.push(g); else flush(false); if (i === sorted.length - 1) flush(true); });
  return best;
}

/** Same over a manager's complete seasons in year order. */
function longestSeasonRun(seasons: ManagerSeason[], pred: (s: ManagerSeason) => boolean, latestYear: number): Run | null {
  const sorted = seasons.filter((s) => s.complete).sort((a, b) => a.year - b.year);
  let best: Run | null = null;
  let run: ManagerSeason[] = [];
  const flush = () => {
    if (run.length && (!best || run.length >= best.length)) best = { length: run.length, from: { year: run[0].year, week: 0 }, to: { year: run[run.length - 1].year, week: 0 }, active: run[run.length - 1].year === latestYear };
    run = [];
  };
  for (const s of sorted) { if (pred(s)) run.push(s); else flush(); }
  flush();
  return best;
}

const latestComplete = (ctx: BoardContext) => Math.max(0, ...ctx.managerSeasons.filter((s) => s.complete).map((s) => s.year));

function runRows(ctx: BoardContext, runOf: (a: CareerAgg) => Run | null, span: (r: Run) => string, activeLabel = 'active'): BoardRow[] {
  const mayBeActive = ctx.year === null || ctx.year === ctx.currentYear;
  const items = byManager(ctx).flatMap((a) => { const r = runOf(a); return r ? [{ userId: a.userId, r, value: r.length, latestYear: r.to.year, latestWeek: r.to.week }] : []; });
  return rank(items).map((i) => ({ key: i.userId, playerId: null, value: i.value, valueLabel: String(i.value), meta: span(i.r), detail: mayBeActive && i.r.active ? activeLabel : null, userId: i.userId, to: null }));
}

export const mWinStreak = (ctx: BoardContext): BoardRow[] => runRows(ctx, (a) => longestGameRun(a.games, (g) => g.result === 'W'), gameSpan);
export const mLoseStreak = (ctx: BoardContext): BoardRow[] => runRows(ctx, (a) => longestGameRun(a.games, (g) => g.result === 'L'), gameSpan);
export const mRun100 = (ctx: BoardContext): BoardRow[] => runRows(ctx, (a) => longestGameRun(a.games, (g) => g.points >= 100), gameSpan);
export const mHighRun = (ctx: BoardContext): BoardRow[] => runRows(ctx, (a) => longestGameRun(a.games, (g) => g.weekHigh), gameSpan);
export const mPlayoffStreak = (ctx: BoardContext): BoardRow[] => runRows(ctx, (a) => longestSeasonRun(a.seasons, (s) => s.playoffBerth, latestComplete(ctx)), seasonSpan);

/** Complete seasons since the manager's last title (or since their first season). */
export const mDrought = (ctx: BoardContext): BoardRow[] => runRows(ctx, (a) => {
  const sorted = a.seasons.filter((s) => s.complete).sort((x, y) => x.year - y.year);
  const lastTitle = sorted.map((s) => s.champion).lastIndexOf(true);
  const since = sorted.slice(lastTitle + 1);
  return since.length ? { length: since.length, from: { year: since[0].year, week: 0 }, to: { year: since[since.length - 1].year, week: 0 }, active: since[since.length - 1].year === latestComplete(ctx) } : null;
}, seasonSpan, 'and counting');
```

```ts
import type { DraftPick, UserId } from '@fantasy-dash/core';
import { fmtSigned } from '../../format';
import { playerName } from '../../players';
import type { BoardContext, BoardRow, Direction } from '../shared';
import { inYear, plural, rank, round1, toneOf } from '../shared';
import { careerMeta } from './shared';

type Valued = DraftPick & { value: number };
interface YearPick { year: number; p: Valued }
const complete = (ctx: BoardContext, year: number) => ctx.managerSeasons.some((ms) => ms.year === year && ms.complete);
/** every valued pick in scope: complete seasons under All-time, the chosen year otherwise */
const valuedPicks = (ctx: BoardContext): YearPick[] => Object.entries(ctx.drafts).flatMap(([y, d]) => {
  const year = Number(y);
  if (!d || !inYear(ctx, year) || (ctx.year === null && !complete(ctx, year))) return [];
  return d.picks.filter((p): p is Valued => p.value !== null).map((p) => ({ year, p }));
});
const slot = (p: DraftPick) => `Rd ${p.round}, pick ${p.pickNo}`;
const signed = (v: number) => fmtSigned(v, 1);
const withTone = (rows: BoardRow[]): BoardRow[] => rows.map((r) => ({ ...r, tone: toneOf(r.value) }));

function classRows(ctx: BoardContext, keep: (yp: YearPick) => boolean, direction: Direction): BoardRow[] {
  const groups = new Map<string, { year: number; userId: UserId; picks: Valued[] }>();
  for (const yp of valuedPicks(ctx).filter(keep)) {
    const k = `${yp.year}|${yp.p.userId}`;
    const g = groups.get(k) ?? { year: yp.year, userId: yp.p.userId, picks: [] };
    g.picks.push(yp.p);
    groups.set(k, g);
  }
  const items = [...groups.values()].map((g) => ({ g, userId: g.userId, value: round1(g.picks.reduce((t, p) => t + p.value, 0)), latestYear: g.year, latestWeek: 0 }));
  return withTone(rank(items, direction).map((i) => ({ key: `${i.g.year}-${i.g.userId}`, playerId: null, value: i.value, valueLabel: signed(i.value), meta: String(i.g.year), detail: plural(i.g.picks.length, 'pick'), userId: i.g.userId, to: `/draft/${i.g.year}` })));
}
function pickRows(ctx: BoardContext, direction: Direction): BoardRow[] {
  const items = valuedPicks(ctx).map((yp) => ({ yp, userId: yp.p.userId, value: round1(yp.p.value), latestYear: yp.year, latestWeek: 0 }));
  return withTone(rank(items, direction).map((i) => ({ key: `${i.yp.year}-${i.yp.p.pickNo}`, playerId: null, value: i.value, valueLabel: signed(i.value), meta: String(i.yp.year), detail: `${playerName(ctx.players, i.yp.p.playerId)} · ${slot(i.yp.p)}`, userId: i.userId, to: `/draft/${i.yp.year}` })));
}

export const mdBestClass = (ctx: BoardContext): BoardRow[] => classRows(ctx, () => true, 'desc');
export const mdWorstClass = (ctx: BoardContext): BoardRow[] => classRows(ctx, () => true, 'asc');
export const mdSteal = (ctx: BoardContext): BoardRow[] => pickRows(ctx, 'desc');
export const mdBust = (ctx: BoardContext): BoardRow[] => pickRows(ctx, 'asc');
export const mdLate = (ctx: BoardContext): BoardRow[] => classRows(ctx, (yp) => yp.p.round >= 9, 'desc');
export const firstRoundEmpty = (): string => 'Needs first-round picks from two complete seasons.';
/** Average first-round pick value per manager over complete seasons, at least two. */
export const mdFirstRound = (ctx: BoardContext): BoardRow[] => {
  const by = new Map<UserId, YearPick[]>();
  for (const yp of valuedPicks(ctx)) if (yp.p.round === 1 && complete(ctx, yp.year)) by.set(yp.p.userId, [...(by.get(yp.p.userId) ?? []), yp]);
  const items = [...by.entries()]
    .filter(([, ps]) => new Set(ps.map((y) => y.year)).size >= 2)
    .map(([userId, ps]) => ({ userId, ps, value: round1(ps.reduce((t, y) => t + y.p.value, 0) / ps.length), latestYear: Math.max(...ps.map((y) => y.year)), latestWeek: 0 }));
  return withTone(rank(items).map((i) => ({ key: i.userId, playerId: null, value: i.value, valueLabel: signed(i.value), meta: careerMeta(i.ps.map((y) => y.year)), detail: plural(i.ps.length, 'first-round pick'), userId: i.userId, to: null })));
};
```

```ts
import type { Transaction, UserId } from '@fantasy-dash/core';
import { fmtPts } from '../../format';
import { playerName } from '../../players';
import { waiverClaims, type WaiverClaim } from '../../waivers';
import type { BoardContext, BoardRow } from '../shared';
import { inYear, plural, rank, round1 } from '../shared';
import { seasonRows } from './shared';

const DAY = 86_400_000;
interface YearTx { year: number; tx: Transaction }
const scoped = (ctx: BoardContext): YearTx[] => ctx.transactions.filter((s) => inYear(ctx, s.year)).flatMap((s) => s.transactions.map((tx) => ({ year: s.year, tx })));
const parties = (tx: Transaction): UserId[] => [...new Set([...tx.adds, ...tx.drops].map((m) => m.userId))];
const isPickup = (tx: Transaction) => (tx.type === 'waiver' && tx.bid !== null) || tx.type === 'free_agent';
const dollars = (v: number) => `$${v}`;
const scopeMeta = (ctx: BoardContext, years: Set<number>) => (ctx.year === null ? plural(years.size, 'season') : String(ctx.year));

interface Event { userId: UserId; year: number; created: number; n: number }
interface Tally { n: number; years: Set<number>; latest: number }
function tally(events: Event[]): Map<UserId, Tally> {
  const out = new Map<UserId, Tally>();
  for (const e of events) {
    const t = out.get(e.userId) ?? { n: 0, years: new Set<number>(), latest: 0 };
    t.n += e.n; t.years.add(e.year); t.latest = Math.max(t.latest, e.created);
    out.set(e.userId, t);
  }
  return out;
}
const events = (ctx: BoardContext, f: (tx: Transaction) => { userId: UserId; n: number }[]): Map<UserId, Tally> =>
  tally(scoped(ctx).flatMap(({ year, tx }) => f(tx).map((e) => ({ ...e, year, created: tx.created }))));
/** One row per manager from a tally; the most recent event breaks ties. */
function tallyRows(ctx: BoardContext, map: Map<UserId, Tally>, label: (v: number) => string, detail: (t: Tally) => string | null = () => null): BoardRow[] {
  const items = [...map.entries()].filter(([, t]) => t.n > 0).map(([userId, t]) => ({ userId, t, value: t.n, latestYear: Math.max(...t.years), latestWeek: 0, secondary: t.latest }));
  return rank(items).map((i) => ({ key: i.userId, playerId: null, value: i.value, valueLabel: label(i.value), meta: scopeMeta(ctx, i.t.years), detail: detail(i.t), userId: i.userId, to: null }));
}
const addsOf = (tx: Transaction) => (tx.type === 'trade' ? [] : tx.adds.map((m) => ({ userId: m.userId, n: 1 })));
const dropsOf = (tx: Transaction) => (tx.type === 'trade' ? [] : tx.drops.map((m) => ({ userId: m.userId, n: 1 })));
const tradesOf = (tx: Transaction) => (tx.type === 'trade' ? parties(tx).map((userId) => ({ userId, n: 1 })) : []);
const bidsOf = (tx: Transaction) => (tx.type === 'waiver' && tx.bid !== null && tx.bid > 0 ? tx.adds.map((m) => ({ userId: m.userId, n: tx.bid! })) : []);
/** per manager-season sums, keyed `${year}|${userId}` */
function perSeason(ctx: BoardContext, f: (tx: Transaction) => { userId: UserId; n: number }[]): Map<string, number> {
  const out = new Map<string, number>();
  for (const { year, tx } of scoped(ctx)) for (const e of f(tx)) out.set(`${year}|${e.userId}`, (out.get(`${year}|${e.userId}`) ?? 0) + e.n);
  return out;
}

export const mtAdds = (ctx: BoardContext): BoardRow[] => tallyRows(ctx, events(ctx, addsOf), String);
export const mtDrops = (ctx: BoardContext): BoardRow[] => tallyRows(ctx, events(ctx, dropsOf), String);
export const mtTrades = (ctx: BoardContext): BoardRow[] => tallyRows(ctx, events(ctx, tradesOf), String);
export const mtBusiest = (ctx: BoardContext): BoardRow[] => {
  const adds = perSeason(ctx, addsOf); const drops = perSeason(ctx, dropsOf); const trades = perSeason(ctx, tradesOf);
  const k = (ms: { year: number; userId: UserId }) => `${ms.year}|${ms.userId}`;
  const total = (ms: { year: number; userId: UserId }) => (adds.get(k(ms)) ?? 0) + (drops.get(k(ms)) ?? 0) + (trades.get(k(ms)) ?? 0);
  return seasonRows(ctx, (ms) => total(ms) || null, String, (ms) => `${plural(adds.get(k(ms)) ?? 0, 'add')} · ${plural(drops.get(k(ms)) ?? 0, 'drop')} · ${plural(trades.get(k(ms)) ?? 0, 'trade')}`);
};
export const mtFaabSeason = (ctx: BoardContext): BoardRow[] => { const bids = perSeason(ctx, bidsOf); return seasonRows(ctx, (ms) => bids.get(`${ms.year}|${ms.userId}`) ?? null, dollars, () => null); };
export const mtFaabCareer = (ctx: BoardContext): BoardRow[] => tallyRows(ctx, events(ctx, bidsOf), dollars);
export const mtBiggestBid = (ctx: BoardContext): BoardRow[] => {
  const items = scoped(ctx).flatMap(({ year, tx }) => (tx.type === 'waiver' && tx.bid !== null && tx.bid > 0 ? tx.adds.map((m) => ({ year, tx, m, userId: m.userId, value: tx.bid!, latestYear: year, latestWeek: tx.week })) : []));
  return rank(items).map((i) => ({ key: `${i.tx.id}-${i.m.playerId}`, playerId: null, value: i.value, valueLabel: dollars(i.value), meta: `${i.year} · Wk ${i.tx.week}`, detail: playerName(ctx.players, i.m.playerId), userId: i.userId, to: null }));
};

const claims = (ctx: BoardContext): WaiverClaim[] => waiverClaims(ctx.transactions.filter((s) => inYear(ctx, s.year)), ctx.lines);
const MIN_SPEND = 25;
function perPoint(ctx: BoardContext, direction: 'asc' | 'desc'): BoardRow[] {
  const by = new Map<UserId, { spent: number; points: number; years: Set<number>; latest: number }>();
  for (const c of claims(ctx)) {
    if (c.bid === null) continue;
    const t = by.get(c.userId) ?? { spent: 0, points: 0, years: new Set<number>(), latest: 0 };
    t.spent += c.bid; t.points += c.points; t.years.add(c.year); t.latest = Math.max(t.latest, c.year * 100 + c.week);
    by.set(c.userId, t);
  }
  const items = [...by.entries()].filter(([, t]) => t.spent >= MIN_SPEND).map(([userId, t]) => ({ userId, t, value: round1(t.spent / Math.max(t.points, 1)), latestYear: Math.max(...t.years), latestWeek: 0, secondary: t.latest }));
  return rank(items, direction).map((i) => ({ key: i.userId, playerId: null, value: i.value, valueLabel: `$${i.value.toFixed(1)}/pt`, meta: scopeMeta(ctx, i.t.years), detail: `$${i.t.spent} · ${fmtPts(round1(i.t.points))} pts`, userId: i.userId, to: null }));
}
export const mtCheap = (ctx: BoardContext): BoardRow[] => perPoint(ctx, 'asc');
export const mtCostly = (ctx: BoardContext): BoardRow[] => perPoint(ctx, 'desc');
export const mtBestPickup = (ctx: BoardContext): BoardRow[] =>
  rank(claims(ctx).map((c) => ({ c, userId: c.userId, value: c.points, latestYear: c.year, latestWeek: c.week })))
    .map(({ c, value }) => ({ key: `${c.year}-${c.week}-${c.playerId}-${c.userId}`, playerId: null, value, valueLabel: fmtPts(value), meta: `${c.year} · Wk ${c.week}`, detail: `${playerName(ctx.players, c.playerId)} · ${c.bid === null ? 'FA' : dollars(c.bid)} · ${plural(c.starts, 'start')}`, userId: c.userId, to: null }));
/** Days between a pickup and the same manager dropping that player, fewest first. */
export const mtQuickCut = (ctx: BoardContext): BoardRow[] => {
  const items: { userId: UserId; playerId: string; value: number; year: number; week: number; latestYear: number; latestWeek: number; key: string }[] = [];
  for (const s of ctx.transactions.filter((x) => inYear(ctx, x.year))) {
    const sorted = [...s.transactions].sort((a, b) => a.created - b.created || (a.id < b.id ? -1 : 1));
    for (const tx of sorted) {
      if (!isPickup(tx)) continue;
      for (const add of tx.adds) {
        const drop = sorted.find((o) => o.created > tx.created && o.drops.some((d) => d.playerId === add.playerId && d.userId === add.userId));
        if (!drop) continue;
        items.push({ userId: add.userId, playerId: add.playerId, value: round1((drop.created - tx.created) / DAY), year: s.year, week: tx.week, latestYear: s.year, latestWeek: tx.week, key: `${tx.id}-${add.playerId}` });
      }
    }
  }
  return rank(items, 'asc').map((i) => ({ key: i.key, playerId: null, value: i.value, valueLabel: `${i.value.toFixed(1)} days`, meta: `${i.year} · Wk ${i.week}`, detail: playerName(ctx.players, i.playerId), userId: i.userId, to: null }));
};
```
