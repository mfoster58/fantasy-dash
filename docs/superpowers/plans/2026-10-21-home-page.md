**Goal:** `/` becomes a home page for the current season with these sections:
- a game-of-the-week banner and two tagged games, both live on game day
- compact standings
- a results card and a top performers card for the week just played
- a gold league leaders band, which moves off the Records page

**Architecture:** Pure helpers in `packages/web/src/lib/home/`:
- `pick.ts` picks the games
- `view.ts` turns a game into what the banner shows
- `results.ts` builds the results quick hitters and top performers
- `leaders.ts` builds the board context for the leaders

`weekStatus` moves from the ticker into `lib/live/` so the ticker and the home page share it. Components live in `components/home/`, and `HomePage` puts them together under the index route, loaded with every season (as Records is).

**Tech Stack:** React 19, react-router 7, Vitest + Testing Library (jsdom, globals on), Tailwind 4, TypeScript. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-21-home-page-design.md`

**Test command for a single file:** `pnpm --filter @fantasy-dash/web exec vitest run <path relative to packages/web>`

**Full suite:** `pnpm test`

**Types:** `pnpm typecheck`

## Global Constraints

**Picking games:**
- The picks never use projections: only records, scoring averages, recent scores and standings.
- The game-of-the-week score is `recordClose × scoringClose × stakes²`.
  - `recordClose = 1 − |winsA − winsB| / weeksPlayed`
  - `scoringClose = 1 − 2·|Φ((ppgA − ppgB) / √(K·(ppgA + ppgB))) − 0.5|`, with `K = 4.4`
  - `stakes` is the average of `(N + 1 − rank) / N`
- Game-of-the-week ties go to the higher combined `seasonPpg`, then the lower `matchupId`.
- Regular-season tags, in priority order, fill two slots:
  - **Upset alert:** the team with fewer wins has the higher average over its last three scores. Of those games, the one with the biggest gap in wins.
  - **Champ watch:** the game with last season's champion.
  - **Top of the table:** the game with the #1 team.
  - **Shootout:** the highest combined `seasonPpg`.
- A game holds at most one slot and is never the game of the week.

**Labels and colours:**
- Tag labels: "Upset alert" (coral), "Champ watch" (turf/`win`), "Top of the table" (accent), "Shootout" (accent), and playoff tags via `fmtTag` (accent).
- State labels are "Projected", "Live" and "Final".
- No winner highlight until `final`. Then the winner is bright and bold and the loser is dimmed.
- Week labels always use the number ("Week 6"), never "last week".

**Rail:**
- Results hitters, in this order: High score, Blowout, Nail-biter. There is no "Left on the bench".
- Top performers:
  - the five highest-scoring starters, ties going to player name
  - three lines per row: the name with position, then the manager, then the stat line
  - points in plain ink

**Leaders:**
- Three columns: Most points, Most yards, Most touchdowns. Yards and TDs each have an All / Pass / Rush / Rec switch.
- A "Beating the model" panel shows FPOE, with an xFP switch.
- Position filter: All / QB / RB / WR / TE.
- Most touches is dropped.

**Links:**
- teams → `/teams/{year}/{userId}`
- players → `/player/{id}`
- box scores → `/scores/{year}/{week}/{matchupId}`
- full table → `/standings/{year}`
- results → `/scores/{year}/{week}`
- top performers → `/stats/players`

**Light and dark:** every colour comes from a theme token in `index.css`, defined for both themes.

## Rulings made while planning

- **The live label is just "Live",** with a red dot. The spec's "plus the ESPN clock of the latest game" is dropped: with ten starters a side, no single clock describes the game, and the per-side "N to play" already says how far along it is. *Cost if wrong:* add `gameLabel` of one starter's game later.
- **`statLine` in the spec becomes `fullStatLine`** in `lib/home/results.ts`. `lib/players.ts` already exports a `statLine(pos, stats)` with a different format, which the box score uses.
  - `fullStatLine` also covers kickers ("3/4 FG, 2/2 XP") and defenses ("2 sck, 1 INT, 1 TD"). Otherwise a top-five K or DEF would show an empty line.
- **"Players left to play"** counts starters whose NFL game is `upcoming` or `live`. When ESPN can't be read (`games === null`), the count is hidden.
- **`HomeStandings` is new.** `StandingsTable` has 13 columns, and the home page shows 7.
- **The leader board definitions keep `sub: 'leaders'`** in `playerBoards.ts`. Only the sub-tab entry leaves `SUB_TABS`, so Records stops showing it while the board functions stay where they are. The "Leaders is skipped" special case in `player/records.ts` goes, since the sub-tab no longer exists.

## Review Focus

1. **Week 1 and the preseason.** Every record is 0-0 and every `seasonPpg` is 0, with no standings ranks and no recent scores.
   - The picks must still return a game of the week (no division by zero, no NaN) and skip Upset alert.
   - The top row is hidden when the week has no games.
   *(Task 2 tests.)*
2. **A week with fewer than three games, or tags that all land on the same game.** No duplicate game, no empty side slots rendered, and the champion's game is never both the game of the week and Champ watch. *(Task 2 tests.)*
3. **The completed season (offseason).** `tickerWeek` returns null, so the home page must fall back to the last week with games and show the championship with 3rd place and the toilet bowl. *(Task 2 test.)*
4. **A tied final, or a tie in High score or margins.** A tied final highlights neither side. Hitter ties go to the lower `matchupId`. *(Task 3 and Task 4 tests.)*
5. **A position filter with no leaders,** such as TE before week 1, or the xFP model with too few lines. Each column shows "No leaders yet." and doesn't crash. *(Task 7 test.)*

```ts
// packages/web/src/lib/live/weekStatus.ts
import type { Game, GameSide, Season, Week } from '@fantasy-dash/core';
import { players } from '../../data/load';
import { playerTeam } from '../players';
import { playerGames } from './gameState';
import type { LiveData } from './LiveProvider';
import { gameOutlook, type GameOutlook } from './outlook';
import { liveWeek } from './overlay';

export interface WeekStatus {
  week: Week;
  isLive: boolean;
  outlookOf: (g: Game) => GameOutlook | null;
  /** starters whose NFL game is upcoming or in progress; null unless live with ESPN read */
  toPlay: (s: GameSide) => number | null;
}

/** A synced week as it stands now: live points and outlooks when it's the live week, the synced week otherwise. */
export function weekStatus(season: Season, wk: Week, live: LiveData): WeekStatus {
  const isLive = live.season?.year === season.year && live.week === wk.week && live.matchups !== null;
  if (!isLive) return { week: wk, isLive, outlookOf: () => null, toPlay: () => null };
  const week = liveWeek(wk, season.managers, live.matchups!, live.stats);
  const gameOf = playerGames((id) => playerTeam(players, id, season.playerTeams), live.games);
  const toPlay = (s: GameSide) => (live.games === null ? null
    : s.starters.filter((e) => e.player && ['upcoming', 'live'].includes(gameOf(e.player.playerId).kind)).length);
  return { week, isLive, outlookOf: (g) => gameOutlook(g, gameOf), toPlay };
}
```

```ts
// packages/web/src/lib/home/pick.ts
import type { Game, GameSide, PlayoffTag, Season, UserId, Week } from '@fantasy-dash/core';
import { K, phi } from '../live/outlook';
import { tickerWeek } from '../live/overlay';

export type RegularTag = 'upset' | 'champ' | 'top' | 'shootout';
export type SideTag = RegularTag | PlayoffTag;
export interface Picks { hero: Game | null; sides: { game: Game; tag: SideTag }[] }

const PLAYOFF_ORDER: PlayoffTag[] = ['Final', 'SF', 'QF', '3rd', '5th', 'Cons-R1', 'Cons-7th', 'Toilet Bowl'];
const COMPLETE_ORDER: PlayoffTag[] = ['Final', '3rd', 'Toilet Bowl'];
const EPS = 1e-9;

/** The week the top row shows: the ticker's week in season, the last week with games once it's over. */
export function homeWeek(season: Season, liveNo: number | null): Week | null {
  const w = tickerWeek(season, liveNo);
  if (w) return w;
  if (season.status !== 'complete') return null;
  return [...season.weeks].reverse().find((x) => x.games.length) ?? null;
}

/** Average of a team's last three regular-season scores before `week`; null with none. */
export function recentAvg(season: Season, userId: UserId, week: number): number | null {
  const pts: number[] = [];
  for (const w of season.weeks) {
    if (w.week >= week || !w.played || w.isPlayoff) continue;
    for (const g of w.games) for (const s of g.sides) if (s.userId === userId) pts.push(s.points);
  }
  const last = pts.slice(-3);
  return last.length ? last.reduce((x, y) => x + y, 0) / last.length : null;
}

const winProb = (a: number, b: number) => (a + b > 0 ? phi((a - b) / Math.sqrt(K * (a + b))) : 0.5);

/** recordClose × scoringClose × stakes²: close records, alike scoring, both teams high in the standings. */
export function gameScore(game: Game, rankOf: (u: UserId) => number | null, teams: number): number {
  const [a, b] = game.sides;
  const played = a.recordBefore.w + a.recordBefore.l + a.recordBefore.t;
  const recordClose = played > 0 ? 1 - Math.abs(a.recordBefore.w - b.recordBefore.w) / played : 1;
  const scoringClose = 1 - 2 * Math.abs(winProb(a.seasonPpg, b.seasonPpg) - 0.5);
  const stake = (s: GameSide) => { const r = rankOf(s.userId); return r === null || teams === 0 ? 1 : (teams + 1 - r) / teams; };
  const stakes = (stake(a) + stake(b)) / 2;
  return recordClose * scoringClose * stakes * stakes;
}

const combined = (g: Game) => g.sides[0].seasonPpg + g.sides[1].seasonPpg;
const has = (g: Game, u: UserId) => g.sides.some((s) => s.userId === u);

function pickPlayoff(games: Game[], order: PlayoffTag[], rankOf: (u: UserId) => number | null): Picks {
  const seed = (g: Game) => Math.min(...g.sides.map((s) => rankOf(s.userId) ?? Infinity));
  const ranked = games
    .filter((g) => g.tag && order.includes(g.tag))
    .sort((x, y) => order.indexOf(x.tag!) - order.indexOf(y.tag!) || seed(x) - seed(y) || x.matchupId - y.matchupId);
  return { hero: ranked[0] ?? null, sides: ranked.slice(1, 3).map((g) => ({ game: g, tag: g.tag! })) };
}

/** The game whose team with fewer wins has the higher recent average; biggest gap in wins first. */
function upsetGame(season: Season, week: number, games: Game[]): Game | undefined {
  let best: Game | undefined; let gap = 0;
  for (const g of games) {
    const [a, b] = g.sides;
    if (a.recordBefore.w === b.recordBefore.w) continue;
    const [under, over] = a.recordBefore.w < b.recordBefore.w ? [a, b] : [b, a];
    const ru = recentAvg(season, under.userId, week); const ro = recentAvg(season, over.userId, week);
    if (ru === null || ro === null || ru <= ro) continue;
    const d = over.recordBefore.w - under.recordBefore.w;
    if (d > gap) { best = g; gap = d; }
  }
  return best;
}

/** Game of the week and up to two tagged games, from synced results only (never projections). */
export function pickGames(season: Season, week: Week, champion: UserId | null): Picks {
  const ranks = new Map(season.standings.map((r) => [r.userId, r.rank]));
  const rankOf = (u: UserId) => ranks.get(u) ?? null;
  const games = [...week.games].sort((x, y) => x.matchupId - y.matchupId);
  if (!games.length) return { hero: null, sides: [] };
  if (week.isPlayoff) return pickPlayoff(games, season.status === 'complete' ? COMPLETE_ORDER : PLAYOFF_ORDER, rankOf);

  const teams = season.standings.length;
  let hero = games[0]; let best = gameScore(hero, rankOf, teams);
  for (const g of games.slice(1)) {
    const s = gameScore(g, rankOf, teams);
    if (s > best + EPS || (Math.abs(s - best) <= EPS && combined(g) > combined(hero))) { hero = g; best = s; }
  }
  const left = games.filter((g) => g !== hero);
  const sides: Picks['sides'] = [];
  const take = (tag: RegularTag, g: Game | undefined) => {
    if (!g || sides.length >= 2) return;
    sides.push({ game: g, tag });
    left.splice(left.indexOf(g), 1);
  };
  take('upset', upsetGame(season, week.week, left));
  take('champ', champion ? left.find((g) => has(g, champion)) : undefined);
  const first = season.standings.find((r) => r.rank === 1)?.userId;
  take('top', first ? left.find((g) => has(g, first)) : undefined);
  take('shootout', left.reduce<Game | undefined>((m, g) => (!m || combined(g) > combined(m) ? g : m), undefined));
  return { hero, sides };
}
```

```ts
// packages/web/src/lib/home/view.ts
import type { Game } from '@fantasy-dash/core';
import { K, phi, type GameOutlook, type LiveStatus } from '../live/outlook';

export interface GameView {
  status: LiveStatus;
  /** projected totals before kickoff, points once it starts */
  scores: [number, number];
  projected: [number, number];
  /** whole percents; null once final */
  win: [number, number] | null;
  /** starters still to play each side; null when unknown */
  toPlay: [number | null, number | null];
  /** index of the winning side, only once final */
  winner: 0 | 1 | null;
}

/** Win % from two projected totals before anything is played. */
export function pregameWin(a: number, b: number): [number, number] {
  if (a + b <= 0) return [50, 50];
  const p = Math.max(1, Math.min(99, Math.round(phi((a - b) / Math.sqrt(K * (a + b))) * 100)));
  return [p, 100 - p];
}

export function gameView(game: Game, outlook: GameOutlook | null, played: boolean, toPlay: [number | null, number | null] = [null, null]): GameView {
  const [a, b] = game.sides;
  const status: LiveStatus = outlook?.status ?? (played ? 'final' : 'upcoming');
  const projected: [number, number] = outlook?.projected ?? [a.projected, b.projected];
  if (status === 'upcoming') return { status, scores: projected, projected, win: outlook?.win ?? pregameWin(projected[0], projected[1]), toPlay, winner: null };
  const scores: [number, number] = [a.points, b.points];
  if (status === 'live') return { status, scores, projected, win: outlook?.win ?? null, toPlay, winner: null };
  return { status, scores, projected, win: null, toPlay: [0, 0], winner: a.points === b.points ? null : a.points > b.points ? 0 : 1 };
}
```

```ts
// packages/web/src/lib/home/results.ts
import type { PlayerDirectory, PlayerId, UserId, Week } from '@fantasy-dash/core';
import { playerName } from '../players';

export interface Hitter { kind: 'high' | 'blowout' | 'nail'; userId: UserId; loser: UserId | null; value: number; matchupId: number }

/** High score, blowout and nail-biter for a played week; ties to the lower matchup id. */
export function weekHitters(week: Week): Hitter[] {
  const games = [...week.games].sort((x, y) => x.matchupId - y.matchupId);
  const out: Hitter[] = [];
  let high: Hitter | null = null;
  for (const g of games) for (const s of g.sides) if (!high || s.points > high.value) high = { kind: 'high', userId: s.userId, loser: null, value: s.points, matchupId: g.matchupId };
  if (high) out.push(high);
  const decided = games.filter((g) => g.winner !== null);
  const hitter = (kind: 'blowout' | 'nail', better: (m: number, best: number) => boolean): Hitter | null => {
    let best: Hitter | null = null;
    for (const g of decided) {
      if (best && !better(g.margin, best.value)) continue;
      const loser = g.sides.find((s) => s.userId !== g.winner)!.userId;
      best = { kind, userId: g.winner!, loser, value: g.margin, matchupId: g.matchupId };
    }
    return best;
  };
  const blowout = hitter('blowout', (m, b) => m > b);
  const nail = hitter('nail', (m, b) => m < b);
  if (blowout) out.push(blowout);
  if (nail) out.push(nail);
  return out;
}

export interface Performer { playerId: PlayerId; userId: UserId; points: number; stats: Record<string, number> }

/** The week's highest-scoring starters; ties by player name. */
export function topPerformers(week: Week, players: PlayerDirectory, n = 5): Performer[] {
  const all: Performer[] = [];
  for (const g of week.games) for (const s of g.sides) for (const e of s.starters) {
    if (e.player) all.push({ playerId: e.player.playerId, userId: s.userId, points: e.player.points, stats: e.player.stats });
  }
  return all
    .sort((x, y) => y.points - x.points || playerName(players, x.playerId).localeCompare(playerName(players, y.playerId)))
    .slice(0, n);
}

const v = (s: Record<string, number>, k: string) => s[k] ?? 0;

/** "23/41, 313 yds, 2 TD · 16 car, 64 yds, 2 TD · 9/10 rec, 53 yds · 1 fum"; zero parts left out. */
export function fullStatLine(s: Record<string, number>): string {
  const parts: string[] = [];
  const td = (n: number, label = 'TD') => (n ? `, ${n} ${label}` : '');
  if (v(s, 'pass_att')) parts.push(`${v(s, 'pass_cmp')}/${v(s, 'pass_att')}, ${v(s, 'pass_yd')} yds${td(v(s, 'pass_td'))}${td(v(s, 'pass_int'), 'INT')}`);
  if (v(s, 'rush_att')) parts.push(`${v(s, 'rush_att')} car, ${v(s, 'rush_yd')} yds${td(v(s, 'rush_td'))}`);
  if (v(s, 'rec') || v(s, 'rec_tgt')) parts.push(`${v(s, 'rec')}${v(s, 'rec_tgt') ? `/${v(s, 'rec_tgt')}` : ''} rec, ${v(s, 'rec_yd')} yds${td(v(s, 'rec_td'))}`);
  if (v(s, 'fga') || v(s, 'xpa')) parts.push(`${v(s, 'fgm')}/${v(s, 'fga')} FG, ${v(s, 'xpm')}/${v(s, 'xpa')} XP`);
  const def = [[v(s, 'sack'), 'sck'], [v(s, 'int'), 'INT'], [v(s, 'def_td'), 'TD']].filter(([n]) => n).map(([n, l]) => `${n} ${l}`);
  if (def.length) parts.push(def.join(', '));
  if (v(s, 'fum_lost')) parts.push(`${v(s, 'fum_lost')} fum`);
  return parts.join(' · ');
}
```

```tsx
const SPLITS: { id: Split; label: string }[] = [{ id: 'all', label: 'All' }, { id: 'pass', label: 'Pass' }, { id: 'rush', label: 'Rush' }, { id: 'rec', label: 'Rec' }];
const chip = (on: boolean) => `rounded-full border px-2.5 py-0.5 font-display text-xs font-bold uppercase tracking-wider ${on ? 'border-gold bg-gold text-[var(--on-chip)]' : 'border-line text-muted hover:text-ink'}`;

function Toggle<T extends string>({ label, options, value, onChange }: { label: string; options: { id: T; label: string }[]; value: T; onChange: (v: T) => void }) {
  return (
    <div role="group" aria-label={label} className="flex flex-wrap gap-1">
      {options.map((o) => <button key={o.id} type="button" aria-pressed={o.id === value} onClick={() => onChange(o.id)} className={chip(o.id === value)}>{o.label}</button>)}
    </div>
  );
}

function Column({ title, rows, season, spotlight = true, control }: { title: string; rows: BoardRow[]; season: Season; spotlight?: boolean; control?: ReactNode }) {
  const top = rows.slice(0, 5);
  const max = Math.max(...top.map((r) => Math.abs(r.value)), 1);
  const team = (r: BoardRow) => (r.userId ? season.managers[r.userId]?.teamName ?? season.managers[r.userId]?.displayName ?? '' : '');
  const [lead, ...rest] = spotlight ? top : [undefined, ...top];
  return (
    <section aria-label={title} className="min-w-0">
      <div className="mb-2 flex items-center justify-between gap-2">
        <h3 className="font-display text-xs font-bold uppercase tracking-[0.14em] text-gold">{title}</h3>
        {control}
      </div>
      {!top.length && <p className="text-sm text-muted">No leaders yet.</p>}
      {lead && (
        <div className="mb-1 grid grid-cols-[64px_1fr] items-end gap-3.5 rounded-xl border border-gold/30 bg-gold/10 p-3">

            <PlayerLink id={lead.playerId!} className="block truncate font-semibold">{playerName(players, lead.playerId!)}</PlayerLink>

            <div className="num text-2xl font-semibold text-gold">{lead.valueLabel}</div>
          </div>
```

```tsx
// packages/web/src/pages/HomePage.tsx
import { useLoaderData } from 'react-router';
import type { Season } from '@fantasy-dash/core';
import HomeStandings from '../components/home/HomeStandings';
import LeadersBand from '../components/home/LeadersBand';
import ResultsCard from '../components/home/ResultsCard';
import TopPerformers from '../components/home/TopPerformers';
import TopRow from '../components/home/TopRow';
import { currentSeason, history } from '../data/load';
import { homeWeek, pickGames } from '../lib/home/pick';
import { useLive } from '../lib/live/LiveProvider';

export default function HomePage() {
  const seasons = useLoaderData() as Season[];
  const live = useLive();
  const season = seasons.find((s) => s.year === currentSeason.year) ?? seasons[seasons.length - 1];
  const champion = history.seasons.find((s) => s.year === season.year - 1)?.honors.champion ?? null;
  const liveNo = live.season?.year === season.year ? live.week : null;
  const thisWeek = homeWeek(season, liveNo);
  const picks = thisWeek ? pickGames(season, thisWeek, champion) : null;
  const results = season.lastScoredWeek > 0 ? season.weeks[season.lastScoredWeek - 1] : null;
  return (
    <div className="space-y-5">
      {thisWeek && picks?.hero && <TopRow season={season} week={thisWeek} picks={picks} champion={champion} />}
      <div className="grid items-start gap-4 lg:grid-cols-[1fr_330px]">
        <HomeStandings season={season} />
        {results && results.games.length > 0 && (
          <div className="space-y-4">
            <ResultsCard season={season} week={results} />
            <TopPerformers season={season} week={results} />
          </div>
        )}
      </div>
      <LeadersBand seasons={seasons} season={season} />
    </div>
  );
}
```
